Herd

Wave Terminal with a pane that watches your Claude Code sessions

A fork of Wave Terminal

Download for macOS Apple Silicon All releases

Setup

  1. Unzip the download, drag Herd.app into /Applications, and open it.
  2. On first launch, Herd copies ~/.config/waveterm into ~/.config/waveterm-herd. If that Wave config has auto-update off, Herd won't check hourly; Herd › Check for Updates still works.
  3. Permission prompts in the Herd pane need a Claude Code PermissionRequest hook. Add this to ~/.claude/settings.json, merging into an existing "hooks" object if there is one: 
    "hooks": {
  "PermissionRequest": [
    {
      "hooks": [
        {
          "type": "command",
          "command": "/Applications/Herd.app/Contents/MacOS/cc-permission-bridge",
          "timeout": 86400
        }
      ]
    }
  ]
}
