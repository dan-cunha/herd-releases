Herd

A fork of Wave Terminal

Download for macOS Apple Silicon All releases

Setup

  1. Unzip the download, drag Herd.app into /Applications, and open it. It's signed and notarized.
  2. On first launch, Herd copies ~/.config/waveterm into ~/.config/waveterm-herd. If that Wave config has auto-update off, Herd won't check hourly; Herd › Check for Updates still works.
  3. The Herd pane needs the Herd menu-bar widget, which provides monitor-dump at ~/Applications/Herd.app. Clone the private dan-cunha/herd repo and run bash scripts/install.sh (needs Swift / Xcode command line tools).
  4. The Herd pane's UI module isn't in the release. Copy ~/Library/Application Support/Herd/ui/ (herd.js, herd.css) from an existing Herd machine to the same path.
  5. Permission prompts in the pane need the PermissionRequest hook from Dan's dotfiles (base/.claude/settings.json). Stow the dotfiles.

Requirements: macOS on Apple Silicon only.
